Protéger tes données

Les données sont synchronisées avec ton espace TradeLog dans le cloud. Exporte régulièrement une sauvegarde JSON et conserve-la dans tes fichiers ou ton espace cloud. Pour transférer ton journal ou restaurer tes données, utilise les fonctions ci-dessous.

L’import ajoute les données sans écraser les données existantes. Les captures restent stockées dans le stockage privé du cloud ; leurs références sont conservées dans la sauvegarde.

À savoir

  • Les données sont associées à ton compte TradeLog.
  • La synchronisation cloud permet de retrouver tes trades sur ordinateur et iPhone.
  • Les fichiers joints sont stockés dans un espace privé.
  • Conserve régulièrement une copie JSON de tes données.
